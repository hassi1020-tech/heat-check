# 現場 AIコンディションチェック Ver.12.0
## 第1段階：顔色・発汗状態解析

Ver.11.3の撮影端末・管理PC分離、Firebase同期、作業員管理、履歴管理を維持したまま、
顔解析の第1段階を追加した版です。

## 今回追加した機能

- 額・左右頬・口元の色特徴解析
- 発赤傾向、蒼白傾向、左右差、色変動のスコア化
- 額・鼻周辺の白色反射から皮膚光沢傾向を解析
- 顔AI総合点、顔色点、発汗傾向点の結果表示
- 解析値を測定履歴・Firestore・CSVへ保存
- 顔画像・動画・Base64画像は保存しない
- 顔色の単一条件だけで全体を「注意」にしない総合判定へ調整

## 重要な制限

第1段階は固定領域のCanvas解析です。
顔の向きや位置が大きくずれると精度が低下します。
発汗量・脱水・熱中症を医学的に診断する機能ではありません。
光沢は照明、皮脂、日焼け止め、雨水等の影響を受けます。

## 次段階

- 第2段階：MediaPipe Face Landmarker導入、表情解析
- 第3段階：目の状態、瞬き、長時間閉眼
- 第4段階：口元、開口、あくび様動作
- 第5段階：5項目の統合校正、個人ベースライン
