# 現場 AIコンディションチェック Ver.12.0
## 第2段階：顔色・発汗・表情解析

第1段階の顔色・皮膚光沢解析を維持し、MediaPipe Face Landmarkerによる
表情係数の端末内解析を追加した版です。

## 今回追加した機能

- MediaPipe Face LandmarkerをWebブラウザ上で起動
- Face Blendshapesを使用した表情変化解析
- 眉周辺の緊張
- 目周辺の細まり・緊張
- 口角低下
- 顎・口周辺の活動
- 表情スコア、解析ラベル、AI信頼度を結果画面へ表示
- 表情解析値を測定履歴・Firestore・CSVへ保存
- 表情だけで直ちに注意判定へ上げず、顔色・発汗等との組合せで評価
- AIモデルが取得できない場合も、従来の顔色・発汗解析で測定を継続

## 通信について

Face Landmarkerのライブラリ、WASM、モデルデータは初回利用時にインターネットから取得します。
一度Service Workerやブラウザキャッシュに保存された後も、端末設定により再取得が必要な場合があります。

## 重要な制限

- 表情解析は疲労、苦痛、感情、熱中症を診断するものではありません。
- マスク、保護眼鏡、ヘルメットの影、逆光、顔の角度で解析精度が低下します。
- 表情スコアは「通常時と異なる可能性がある顔の動き」の補助指標です。
- 顔画像・動画は保存しません。保存するのは数値化した解析結果のみです。
