# 現場 AIコンディションチェック Ver.14.0 UIリニューアル版

総合判定、作業可否、顔色・表情・瞬き／眠気・疲労、疲労指数、推奨対応を常時表示します。
発汗傾向、目の状態、寝不足傾向、集中力低下、体調変化、判定品質・信頼度は折りたたみ表示です。

AI判定ロジック、Firebase同期、保存データ、管理画面はVer.13.5.1を維持しています。
