# 現場 AIコンディションチェック Ver.11.0

## 目的
建設現場での非接触スクリーニング用Webアプリです。疾病・熱中症・脱水の医療診断は行いません。

## Ver.11.0の再設計
- マスタ、設定、測定、実証評価を単一データ `heatCheckV11` に統合
- 実証評価記録、管理者ダッシュボード、作業員別カルテは同じ `records` を参照
- 顔画像・動画は保存せず、明るさ・色差・左右差・動きの数値のみ保存
- 作業員ID、現場、作業班の追加・更新・削除を統一
- JSONバックアップ・復元、CSV出力
- 旧Ver.10系のJavaScriptや保存キーには依存しない

## GitHub Pagesへの反映
ZIP内の7ファイルをリポジトリ直下へすべて上書きしてください。

公開後は次の形式で開きます。
`https://hassi1020-tech.github.io/heat-check/?v=1100`

## 注意
通常カメラだけで皮膚温、深部体温、発汗量、脱水状態を直接測定することはできません。本人の申告と管理者判断を優先してください。


## Ver.11.1 変更内容
- AIコンディション評価を、総合判定・判定理由・今すぐ実施すること・AI測定結果・測定品質を表示する構成へ変更
- カメラ画面に顔の楕円、目・鼻・顎の測定位置ガイドを追加
- 作業員マスタから作業負荷を削除
- 作業負荷による判定処理と保存項目を削除
- Ver.11.0の保存データはそのまま読み込み可能。旧データに残る作業負荷は表示・判定に使用しない
- キャッシュ番号を1101へ更新


## Ver.11.2 第2段階
- 結果画面を「判定／AIコンディション評価／判定理由／今やること」に再構成
- 危険度スコア、判定レベル一覧、AI分析ポイントカード、AIからのひとことを非表示
- 数値指標は「詳細を見る」に収納
- 最上位判定名を「作業中止」に統一
- カメラ映像の明るさ・左右差を利用したリアルタイム撮影案内を追加
- 顔ガイドを適正時は緑、要調整時は橙で表示
- 測定中は顔ガイドを点滅表示
- 顔画像・動画は保存せず、数値と判定結果のみLocalStorageへ保存


## Ver.11.2 第3段階
- 管理者ダッシュボードを追加
- 本日の測定件数、注意以上件数、登録作業員数、平均信頼度を表示
- 通常・注意・警戒・作業中止の判定別集計を表示
- 直近の要確認結果を一覧表示
- 作業員別カルテに測定回数、最新判定、注意以上回数、直近10回の推移を表示
- 測定履歴CSV出力を追加
- LocalStorage全体のJSONバックアップ・復元を追加
- CSV・JSONには顔画像や動画を含めない
- キャッシュ番号を1102s3へ更新


## Ver.11.2 第4段階
- PCで作成した現場運用マスタをJSON形式で出力可能
- スマホ側で現場運用マスタJSONを取込み可能
- 測定履歴を削除せず、マスタデータのみを更新
- 「既存マスタへ追加・同一IDは上書き」と「全置換」を選択可能
- 現場、班、作業員、運用設定を一括移行
- マスタ版番号、最終更新日時、現場数、作業員数を表示
- マスタファイルには測定履歴、顔画像、動画を含めない
- 不正なJSONや通常バックアップJSONの誤取込みを防止
- キャッシュ番号を1102s4へ更新

## PCからスマホへ反映する手順
1. PCで現場、班、作業員等の運用マスタを作成
2. 管理者ダッシュボードの「マスタのみ出力」を押す
3. 出力されたJSONをメール、Teams、Dropbox等でスマホへ送る
4. スマホでアプリを開き「マスタのみ取込」を押す
5. JSONを選択し、追加・上書き又は全置換を選択して反映

測定履歴は端末ごとに保持され、マスタ取込みでは削除されません。
