# 現場 AIコンディションチェック Ver.12.0（試作版）

## 実装内容
- MediaPipe Face Landmarkerによる顔検出・顔ランドマーク
- 額付近の緑色成分時系列からrPPG心拍数を推定
- 鼻位置の低周波変動から呼吸数を試験的に推定
- 眼周囲ランドマークから瞬きを推定
- 鼻位置の標準偏差から頭部揺れを算出
- 額付近のRGB値から顔色指標を算出
- WBGT、水分補給、体調、睡眠を入力
- 過去の正常測定値から本人ベースラインを作成
- ルールベースの総合リスク判定
- 顔画像・動画は保存しない
- 測定数値をlocalStorageへ保存しCSV出力

## 起動方法
GitHub PagesなどHTTPS環境へ一式をアップロードしてください。
カメラAPIはHTTPSまたはlocalhostでのみ使用できます。

ローカル試験例:
python -m http.server 8000
http://localhost:8000

## 重要
この版は「学習済み熱中症診断AI」ではなく、各センサー値の取得とデータ蓄積を行う試作版です。
rPPGと呼吸数は照明、端末性能、動作、肌の映り方で大きく変動します。
医療判断には使用せず、実証試験で基準機器との比較検証を行ってください。
