# 現場 AIコンディションチェック Ver.13.3

Ver.13.2のFirebase同期・Googleログイン機能を維持し、現場管理画面を強化した版です。

## 追加した管理機能

- 現場管理ダッシュボード
- 登録者数、測定済み、未測定、注意、警戒、作業中止の人数集計
- 日付・現場・班・判定による絞り込み
- 氏名・作業員ID検索
- 作業員ごとの最新判定カード
- 優先確認リスト
- 現場・班別の測定状況
- 直近の測定一覧
- 管理画面の印刷
- 1分ごとの自動再集計
