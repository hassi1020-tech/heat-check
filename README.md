# 現場 AIコンディションチェック Ver.12.0 第4段階
## 体調変化・疲労・寝不足・集中力低下の補助検知版

口元AIは使用していません。

### 実装内容
- 顔色AI
- 皮膚光沢による発汗傾向
- MediaPipe Face Landmarkerによる表情解析
- 目の開閉、開眼率、瞬き、最大閉眼時間
- 頭部動揺の参考値
- 疲労傾向指数
- 寝不足傾向指数
- 体調変化指数
- 集中力低下傾向指数
- 個人ベースライン比較
- AIコメントと行動案内
- CSV・JSON出力
- 顔画像・動画は非保存

### 個人ベースライン
本人申告が「異常なし」、総合判定が「通常」、測定品質65%以上の記録だけを使用します。
初期設定では正常記録5件で比較を開始し、直近10件を通常値として使用します。

### 重要
各指数は疾病、熱中症、睡眠障害、疲労、意識状態を診断しません。
「本人の通常時と異なる可能性」を管理者へ示すスクリーニング補助です。
