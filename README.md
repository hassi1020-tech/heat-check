# 現場 AIコンディションチェック Ver.12.0
## 第3段階：顔色・発汗・表情・目の状態解析

第2段階までの機能を維持し、MediaPipe Face Blendshapesを使った
目の開閉状態の時系列解析を追加した版です。

## 今回追加した機能

- 左右のeyeBlink係数を時系列取得
- 平均開眼率
- 瞬き回数
- 測定時間から換算した瞬き回数/分
- 最大閉眼時間
- 800msを超える長時間閉眼回数
- 両眼閉眼比率
- 左右の目の状態差
- 目の状態スコアと解析ラベル
- 結果、Firestore、履歴、CSVへの数値保存
- 目の状態だけで即座に注意判定へ上げず、顔色・表情等との組合せで評価

## 測定時の注意

- 正面を向き、顔全体と両目をガイド内に入れてください。
- 保護眼鏡、色付き眼鏡、前髪、ヘルメットの影、逆光は精度を低下させます。
- 10秒程度の短時間測定では、瞬き回数/分は参考換算値です。
- 意識的に目を閉じたり、測定中に話したりすると結果が変化します。

## 重要な制限

本機能は眠気、意識障害、熱中症、疲労を診断するものではありません。
RGBカメラとFace Blendshapesから得られる目の開閉傾向を補助情報として表示します。
顔写真・動画は保存しません。
