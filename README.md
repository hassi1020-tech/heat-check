# 現場 顔動画コンディションチェック MVP

スマートフォンの前面カメラで顔動画を5秒準備後、約25秒測定し、顔周辺の色変化から推定脈拍、映像の動き、明るさ、顔色変化の傾向を算出して、緑・黄・橙・赤の4段階で表示する試作版です。

## 重要

- 医療機器ではありません。
- 熱中症、脱水、疾病を診断しません。
- 緑判定は安全や作業継続可能を保証しません。
- 本人に異常がある場合は、結果にかかわらず作業を中止し、管理者が対面確認してください。
- 顔画像と動画は保存しません。測定結果だけをブラウザの localStorage に保存します。

## 起動方法

カメラ利用には HTTPS または localhost が必要です。

### PCで試す

このフォルダで次を実行します。

```bash
python -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000
```

### スマートフォンで試す

最も簡単なのは、GitHub Pages、Cloudflare Pages、Netlifyなどの無料HTTPSホスティングへフォルダ一式を配置する方法です。

社内・現場運用前には、情報システム部門や個人情報管理責任者の確認を受けてください。

## 主な機能

- 作業員ID、氏名、現場名、測定区分の入力
- 前面カメラによる15秒測定
- 実験的なrPPG推定脈拍
- 明るさ、動き、顔色変化、信号品質の評価
- 作業員ごとの過去5回中央値を通常値として利用
- 緑・黄・橙・赤判定
- 第三者向け管理一覧
- CSV出力
- PWA対応
- 画像・動画を保存しないローカル処理

## 判定概要

- 黄：水分・塩分補給、再測定
- 橙：作業中断、休憩、管理者確認
- 赤：橙が短時間に連続した場合に作業中止・対面確認
- 測定品質不良：黄として再測定

しきい値は設定画面から変更できます。

## 現時点の限界

- ブラウザ上の簡易アルゴリズムなので、医療用測定精度はありません。
- 日光、蛍光灯のちらつき、顔の動き、汗、日焼け、マスク、カメラ自動露出の影響を受けます。
- 一部ブラウザでは FaceDetector API が使えないため、画面中央の固定領域を解析します。
- 端末間でデータ共有はしません。複数端末共有にはGoogle Apps Script、Firebase、Supabase等の追加実装が必要です。

## 実運用へ進める前に必要なこと

1. 同一人物で安静時と作業後を複数回測定し、再現性を検証
2. WBGT計、体温、本人申告、管理者所見との照合
3. 誤判定率と見逃し率の評価
4. 産業医、安全衛生担当者による判定基準レビュー
5. 顔情報の利用目的、同意、保存期間、閲覧権限の規程化
6. 端末間共有、管理者通知、アクセス制御の追加

## v2での改良点

- 5秒間の準備時間を追加し、カメラ自動露出が落ち着いてから測定
- 本測定を25秒に延長
- 約20fpsで安定取得
- 周波数解析で45～150bpmの範囲から脈拍候補を算出
- 手ぶれ・明るさ・信号ピークを使った品質判定
- 品質が悪い場合は体調判定せず「判定保留」と表示
- 顔動画だけで赤判定を出しにくい安全側の設計

GitHubへ更新する場合は、README.md、index.html、app.jsを含む全ファイルを上書きアップロードしてください。

## Ver.7 主な改良

- 額・左右頬の3領域を同時解析
- 正規化色差（POSに近い簡易方式）で照明変動を低減
- 測定前半・後半の脈拍推定差を「安定性」として評価
- 45 bpmや150 bpm付近など周波数端への張り付き値を無効化
- 複数領域の脈拍値が一致しない場合に品質を減点
- WBGT、作業強度、水分補給、本人申告、自覚症状を総合判定へ追加
- 重大な自覚症状がある場合は、カメラ結果より優先して赤判定
- 通常カメラで皮膚温・発汗量を直接測れるような表示は行わない
- CSVへWBGT・作業強度・水分補給・本人申告・安定性を追加

本版も医療機器ではなく、現場の対面確認を補助する試作版です。


## Ver.8 顔状態チェック版（脈拍なし）
- 脈拍推定を完全に削除
- 額・左右頬の色、明るさ、赤み、青白さ傾向を解析
- 測定前半と後半の顔色変化を比較
- 左右頬の差と顔の動きを評価
- WBGT、作業強度、水分補給、本人申告、自覚症状を総合判定
- 画像・動画は保存せず、数値結果のみ端末保存

通常のスマートフォンカメラだけでは、熱中症、脱水、体温、皮膚温、発汗量を診断・直接測定できません。
本アプリは声掛け、再測定、管理者による対面確認を補助する試作版です。

## 危険度スコアについて
危険度スコアは、学習済みの医療AIによる診断値ではありません。
保存済みデータと入力条件を組み合わせた試験的なルール評価です。

スコアは以下の用途に限定してください。
- 管理者が確認する順番の整理
- 同一作業員の変化確認
- 再測定や対面確認のきっかけ
- 実証試験データの蓄積

以下には使用しないでください。
- 熱中症や疾病の診断
- 作業可否の自動決定
- 医療機関受診の要否をアプリだけで決定
- 人事評価や不利益な判断

## 悪化傾向について
「30～60分以内」などの表示は発症時刻の予測ではありません。
直近のスコア変化に応じた管理者の再確認目安です。

本人に意識障害、会話異常、けいれん、歩行困難、強い頭痛、吐き気などがある場合は、
スコアに関係なく作業を中止し、現場の緊急対応手順に従ってください。
