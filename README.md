# 現場 AIコンディションチェック Ver.13.4

Ver.13.3のFirebase同期・現場管理画面を維持し、AIコンディション判定を強化した版です。

## 強化内容

- 顔色特徴の照明変動補正
- 顔検出率、照明品質、顔の安定性から判定信頼度を算出
- 瞬き回数だけでなく閉眼割合（PERCLOS）を追加
- 平均閉眼時間、最大閉眼時間、0.5秒以上の閉眼を記録
- 瞬き・閉眼パターンの総合点を追加
- 表情の平均値だけでなく測定中の変動量を追加
- 眉周辺、目の細め、口周辺の顔筋特徴を数値化
- 本人通常値との比較に閉眼割合・閉眼時間を追加
- 測定信頼度60%未満では再測定を推奨
- CSV出力項目を拡張

## 重要

本機能は学習済み医療AIによる診断ではありません。
MediaPipeの顔特徴量、本人通常値、問診、WBGTを統合した安全管理支援用のルール判定です。
顔画像と動画は保存しません。
